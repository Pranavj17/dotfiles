# VPN Setup & Troubleshooting

## Tunnelblick Configuration
- Primary VPN client for macOS
- Configuration stored in Tunnelblick config folder
- Supports multiple VPN profiles for different networks

## Slack Connectivity Diagnostics
- Network issues often surface in Slack (slow message delivery, connection drops)
- VPN state changes can affect integration with Scripbox services
- Test connectivity by monitoring message lag and real-time sync performance
