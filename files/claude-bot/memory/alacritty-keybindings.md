# Alacritty Keybindings

Custom keybindings configured in Alacritty for terminal efficiency:

## Key Mappings
- **Alt+U**: Navigate/open URLs in terminal output
- Other productivity shortcuts for common shell operations

## Configuration
- Stored in ~/.config/alacritty/alacritty.toml
- Synced via dotfiles or direnv environment
